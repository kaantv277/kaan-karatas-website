# Kaan Karataş — Personal Academic Website

A responsive static website built with HTML, CSS, and minimal JavaScript.

## Local preview
Open `index.html` in a web browser.

## Publish with GitHub Pages
Upload the contents of this folder to the root of the public GitHub repository. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.

## Update
Edit the relevant HTML page or `css/style.css`, then upload changed files to the same paths and commit.

## Privacy
No analytics, tracking cookies, forms, or external JavaScript libraries. The skyline artwork is CSS-based. Fonts use local system fonts; there are no external font requests.

## Personal information
The About and Contact sections are placeholders. Add personal details only after reviewing and approving the exact text.
